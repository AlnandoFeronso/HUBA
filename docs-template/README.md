# Documentation template

## How to use

1. Copy blank-template.md next to your other docs and rename it
2. Copy any extra element you need from elements.md
3. Skim GUIDELINES.md once

## Files

| File | What it is |
|------|------------|
| blank-template.md | Base document template with fields |
| elements.md | Extra reusable components |
| GUIDELINES.md | Writing and formatting rules |
| example-structure.md | Folder layout example
