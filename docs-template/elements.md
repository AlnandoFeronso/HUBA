# Elements to copy

Copy a snippet into your document and edit it.

## Paragraph

Use plain text for simple statements.

```markdown
This is a paragraph with some text.
```

## Bullet list

Use unordered lists for items without specific order.

```markdown
- First level item 1
  - Second level item 1.1
  - Second level item 1.2
- First level item 2
```

## Numbered list

Use ordered lists for sequences or steps.

```markdown
1. First step
2. Second step
3. Third step
```

## Table

Use tables to organize data in columns and rows.

```markdown
| Column 1 | Column 2 | Column 3 |
|----------|----------|----------|
| Data A   | Data B   | Data C   |
| Data D   | Data E   | Data F   |
```

## Figure with caption

Use figures to include images with captions.

```markdown
![Short description](assets/figure-name.png)
*Figure 1. Caption text.*
```

## Code block

Use code blocks for programming or technical content.

````markdown
```python
def example():
    print("Hello, World!")
```
````

## Note and warning

Use callout blocks to highlight important information.

```markdown
> [!NOTE]
> This is a note for important information.

> [!WARNING]
> This is a warning for critical alerts.
```

## Checklist

Use checklists for tasks or requirements.

```markdown
- [ ] Task 1
- [ ] Task 2
- [ ] Task 3
```

## Equation

Use equations for mathematical expressions.

```markdown
$$ m_i = \operatorname{sgn}\big(\tanh(I_i) - r\big), \quad r \sim U(-1, 1) $$

The symbols represent: m_i is the output value, I_i is the input signal, sgn is the sign function, tanh is the hyperbolic tangent, and r is a random variable uniformly distributed between -1 and 1.
```

## Link to another document

Use links to reference related documentation.

```markdown
[Document title](../hardware/example.md)
```
